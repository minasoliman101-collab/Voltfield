Embed this calculator

Writing about this, or teaching it? Paste the snippet below into any web page to add a working copy of this calculator. It is free, runs entirely in the reader’s browser, sends nothing anywhere, and links back to this page for the method.

<div class="vf-calc-widget" data-calc="{{SLUG}}"></div>
<script src="https://voltfield.org/embed/calculator-widget.js" async></script>

Also available: voltage-drop, transformer-sizing and power-factor. Change data-calc to switch.
