Electrical Practice Questions

138 multiple-choice questions in 17 sets, each with a worked solution that shows where the wrong answers come from.

Pick a set, answer the questions, and check each one as you go. Every question has four choices, and the wrong ones are not random: each is what you get from a particular mistake, such as leaving out the square root of three or using a one-way length where the current goes out and back. The solution names the mistake as well as the method.

How to use them

Work each question on paper before looking at the choices. If your answer is not among them, that tells you something before you have checked anything. When you get one wrong, read the solution and then try the linked calculator with different numbers until the method is familiar. Your answers are kept in your browser, so you can leave a set and come back to it.

What these are and are not

These are original questions written for study. They are not taken from any licensing or certification examination and are not affiliated with one. Where a question touches the National Electrical Code it tests a method, such as taking a continuous load at 125 percent, and not a table lookup, so it does not depend on which edition you are working to. The one exception is the set on ground-fault protection, which tests rules stated in the code itself and says which edition it follows. Every question also has a page of its own, linked from its solution, if you want to send one to somebody. For the terms themselves there is also a glossary quiz, and the one-line practice sandbox lets you build a system and have it checked.
