Changelog

What's new

A dated log of what's shipped — new guides, calculators, and tools, in the order they landed. Most recent first. Recent themes: sourcing-compliance guides (grid interconnection, Buy America), site-wide search, and ways to find every free tool and calculator in one place.

August 23, 2026
Leading with the tools, not the catalog: the homepage, sector pages, and nav now put the free calculators, practice tools, and guides first — the catalog reference data is still there, just no longer the front door.
  • New: POD & Skid Designer — size a modular power block (transformer, switchgear, distribution, backup, cooling) against a target load and redundancy level (N/N+1/2N), with 4 built-in challenge scenarios and an enclosed-POD/open-frame-skid toggle
  • Data Centers, Renewables, and Battery Storage sector pages rebuilt as full guides — redundancy, DC:AC ratio, C-rate, grid-forming PCS, and more — each with a dedicated tools section
  • Author byline and publish date added to all 11 technical guides, linked to a new "how the guides are written" section on the methodology page
  • Homepage hero and search now lead with the free tools; hero search now searches guides/calculators/tools instead of the parts catalog
  • 3 new guides on region-specific interconnection timelines: PJM, MISO, and ERCOT — each linked from the general interconnection process guide
  • Shared header/nav/token CSS extracted into a cached voltfield-core.css instead of duplicated inline on every page
  • A real, crawlable reference photo (with the same AI-illustration disclosure used sitewide) now appears on part detail pages, alongside the category icon
  • Pseudo-3D tile treatment on every category/tool icon site-wide (CSS perspective transform, no external assets)
  • Real procedural 3D models on the part detail page — genuine rotatable Three.js geometry (not a photo, not the CSS icon treatment), loaded on demand with a "View in 3D" toggle
  • New: Rack Elevation Builder — stack equipment into a 24/42/48U rack and check U-space, circuit power (NEC 80% continuous-load derate), and weight budgets
  • 4 new standalone guides on concepts that were previously only a paragraph inside a sector page: PUE Explained, Liquid Cooling vs. Air Cooling, BESS Augmentation Explained, and Inverter Clipping Ratio Explained
  • HowTo structured data added to the Practice Sandbox, POD & Skid Designer, and Rack Elevation Builder
  • Drilling & Completions and Industrial Supply sectors now surface their relevant free tools (BOM Generator/Match, Part ID, Specification Checklist) instead of only catalog links

  • Sitewide SEO pass: canonical tags on every page, title/H1 alignment, added structured data where it was missing
